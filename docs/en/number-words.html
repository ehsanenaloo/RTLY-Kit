Converting numbers to words#

NumberToWords::convert() spells an integer out as words. Persian (fa) is the default and covers every integer below 1021.

<?php
require 'vendor/autoload.php';

use RtlyKit\Number\NumberToWords;
use function RtlyKit\number_to_words;

echo NumberToWords::convert(0), "\n";        // صفر
echo NumberToWords::convert(21), "\n";       // بیست و یک
echo NumberToWords::convert(115), "\n";      // صد و پانزده
echo NumberToWords::convert(1001), "\n";     // یک هزار و یک
echo NumberToWords::convert(12345), "\n";    // دوازده هزار و سیصد و چهل و پنج
echo NumberToWords::convert(-45), "\n";      // منفی چهل و پنج
echo number_to_words(2000000000), "\n";      // دو میلیارد
echo NumberToWords::convert(1234567), "\n";
// یک میلیون و دویست و سی و چهار هزار و پانصد و شصت و هفت

Words are joined with « و » (and) between every part, and each scale word follows its group: «هزار» (103), «میلیون» (106), «میلیارد» (109), «تریلیون» (1012), «کوادریلیون» (1015) and «کوینتیلیون» (1018). A group equal to 1 keeps its «یک» (1000 is «یک هزار»; to read a bare «هزار» use fromWords(), below). Zero groups are skipped.

Accepted input#

The parameter is typed int|float|string:

  • int: the whole PHP range works, including PHP_INT_MAX: «نه کوینتیلیون و دویست و بیست و سه کوادریلیون ...».
  • float: must be finite and integral. 3.0 gives «سه»; 1.5 throws instead of being silently truncated.
  • string: an optional sign and digits in any digit set. Commas, ٬ and spaces are removed, so a number copied from a form works. Strings can be longer than a PHP int, up to 21 digits after leading zeros are dropped.
echo NumberToWords::convert('۱۲۳٬۴۵۶'), "\n";        // صد و بیست و سه هزار و چهارصد و پنجاه و شش
echo NumberToWords::convert('1,000,000'), "\n";      // یک میلیون
echo NumberToWords::convert('+7'), "\n";             // هفت
echo NumberToWords::convert('-0'), "\n";             // صفر
echo NumberToWords::convert('999999999999999999999'), "\n";
// نهصد و نود و نه کوینتیلیون و نهصد و نود و نه کوادریلیون ... و نهصد و نود و نه

Errors#

Invalid input throws InvalidNumberException (a subclass of RtlyKitException). Read the stable code with getErrorCode():

InputError code
1.5, '12a', ''invalid_number
NAN, INFnon_finite_number
A string longer than 4096 bytesinput_too_long
1e21, '1000000000000000000000' (22 digits)number_too_large
 
try {
    NumberToWords::convert('1000000000000000000000');
} catch (\RtlyKit\Exceptions\InvalidNumberException $e) {
    echo $e->getMessage(), ' [', $e->getErrorCode()->value, "]\n";
    // Number is too large (limit is 10^21 - 1). [number_too_large]
}

See Error handling for how to catch every library exception with one type.

Arabic#

Pass 'ar' as the second argument for Modern Standard Arabic. The locale is matched on its first two letters, case-insensitively, so 'ar_SA' and 'AR' work and so do 'fa_IR' for Persian.

echo NumberToWords::convert(11, 'ar'), "\n";        // أحد عشر
echo NumberToWords::convert(21, 'ar'), "\n";        // واحد وعشرون
echo NumberToWords::convert(200, 'ar'), "\n";       // مئتان
echo NumberToWords::convert(3000, 'ar'), "\n";      // ثلاثة آلاف
echo NumberToWords::convert(2000000, 'ar'), "\n";   // مليونان
echo NumberToWords::convert(1002003, 'ar'), "\n";   // مليون وألفان وثلاثة
echo NumberToWords::convert(-7, 'ar'), "\n";        // سالب سبعة

The Arabic output follows these rules, and its limits are real:

  • Range: the absolute value must be below 109 (up to 999,999,999). A larger number throws number_too_large. The converter is tested for 0 to 999,999,999 and for negatives.
  • Masculine counting form only. There is no gender agreement with the counted noun, no case endings and no tanwin.
  • Compound groups are plain. A group such as 102 in 102,000 uses the ordinary compound form («مئة واثنان ألف») without the special construct-state rules some style guides require.
  • Negative numbers are prefixed with «سالب».
Known limitation. Treat the Arabic output as a readable spelled-out number, not as legal or typeset-quality text for a cheque. If the counted noun's gender or grammatical case matters, review the phrase by hand.

An unsupported locale throws UnsupportedLocaleException with the code unsupported_locale:

try {
    NumberToWords::convert(5, 'en');
} catch (\RtlyKit\Exceptions\UnsupportedLocaleException $e) {
    echo $e->getMessage(), "\n";   // Unsupported locale 'en' (use 'fa' or 'ar').
}

From words back to a number#

NumberToWords::fromWords() is the inverse of the Persian conversion for the forms convert() produces. It returns an int when the value fits in a PHP int and a digit string otherwise.

var_dump(NumberToWords::fromWords('بیست و سه'));                 // int(23)
var_dump(NumberToWords::fromWords('منفی چهل و دو'));             // int(-42)
var_dump(NumberToWords::fromWords('هزار و یک'));                 // int(1001)
var_dump(NumberToWords::fromWords('دو میلیون و سیصد هزار و پنج')); // int(2300005)

// Round trip across the whole range:
var_dump(NumberToWords::fromWords(NumberToWords::convert(PHP_INT_MAX)));
// int(9223372036854775807)
var_dump(NumberToWords::fromWords(NumberToWords::convert('999999999999999999999')));
// string(21) "999999999999999999999"

How words are read#

  • Input is normalized first: Arabic letter variants become Persian («ك» to «ک», «ي» to «ی»), a ZWNJ counts as a space, and extra whitespace is ignored.
  • A leading «منفی» makes the result negative; «منفی صفر» is 0.
  • A scale word without a preceding number means one, so «هزار» is 1000.
  • Scales must be in descending order: «هزار هزار» or «هزار میلیون» throw.
  • No group may exceed 999.
  • The word «و» is skipped wherever it appears.
try {
    NumberToWords::fromWords('یکصد');
} catch (\RtlyKit\Exceptions\InvalidNumberException $e) {
    echo $e->getMessage(), ' [', $e->getErrorCode()->value, "]\n";
    // Unknown number word 'یکصد'. [invalid_number_words]
}

Errors carry the code invalid_number_words (unknown word, ill-formed sequence, scales out of order, empty text) or input_too_long for text over 4096 bytes.

Lenient reader. fromWords() adds up the values inside each group without checking natural word order, so unusual phrases such as «دو صد» (102) or a stray trailing «و» are accepted. It is a reader for text produced by convert() and for ordinary hand-written numbers, not a grammar checker; validate untrusted wording yourself. Only the Persian form is read: Arabic words from convert($n, 'ar') and ordinals such as «سی‌ام» are not understood and throw. The compact spelling «یکصد» is also unknown.
