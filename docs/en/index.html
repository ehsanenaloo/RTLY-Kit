RTLY-Kit

The Persian and Arabic RTL toolkit for PHP

Jalali, Hijri and Hebrew calendars, Iranian validators, Persian and Arabic numbers and text, holidays and prayer times in one typed, immutable PHP library. Carbon and Laravel integrations are optional.

Quick startAll guidesRepository on GitHub ↗

Requires PHP 8.2 or newer; only the mbstring extension is needed. MIT licensed.

Install

Install with Composer and use it right away. There is no config file and no publish step.

composer require enaxon/rtly-kit

The 30-second example

use function RtlyKit\{jdate, to_persian, is_national_code};

echo jdate('2026-03-21')->format('l j F Y');   // شنبه 1 فروردین 1405
echo to_persian(1405);                         // ۱۴۰۵
var_dump(is_national_code('0499370899'));      // bool(true)

What you can do

Each item links to its guide.

  • Create, format, add to, compare and convert Jalali, Hijri and Hebrew dates.
  • Validate national codes, Sheba numbers, bank cards, mobile numbers, postal codes and vehicle plates and get machine-readable error codes.
  • Convert between Persian, Arabic and English digits and format numbers with thousands separators.
  • Write numbers as Persian or Arabic words and use ordinals.
  • Normalize text (Arabic ka and ya, ZWNJ), detect direction and script, and build Persian slugs.
  • Ask whether a day is an Iranian public holiday and find the next business day.
  • Compute prayer times for a city and a calculation method.
  • Use the Carbon macros and the Laravel validation rules, facade and Eloquent cast with no extra setup.
