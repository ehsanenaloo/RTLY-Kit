شروع سریع#

<?php
require 'vendor/autoload.php';

use RtlyKit\Validation\NationalCode;

var_dump(NationalCode::isValid('0499370899'));      // bool(true)
var_dump(NationalCode::isValid('۰۴۹۹۳۷۰۸۹۹'));      // bool(true)، ارقام فارسی
var_dump(NationalCode::isValid('049-937-0899'));    // bool(true)، خط تیره حذف می‌شود

$result = NationalCode::validate('0499370899');
echo json_encode($result->details(), JSON_UNESCAPED_UNICODE);
// {"normalized":"0499370899","location":{"province":"تهران","city":"شهرری"}}

این کلاس قرارداد Validator را پیاده می‌کند؛ پس validate() یک Result برمی‌گرداند و برای ورودی بد هیچ استثنایی نمی‌اندازد. توابع کمکی RtlyKit\is_national_code() و RtlyKit\validate_national_code() هستند:

use function RtlyKit\is_national_code;
use function RtlyKit\validate_national_code;

var_dump(is_national_code('۰۴۹۹۳۷۰۸۹۹'));                  // bool(true)
print_r(validate_national_code('0499370898')->errors());  // Array ( [0] => invalid_checksum )

چه چیزی بررسی می‌شود#

بررسی‌ها به این ترتیب انجام می‌شود و با اولین شکست متوقف می‌شود:

  1. نوع و اندازه. رشته، int و float صحیح پذیرفته می‌شود؛ هر چیز دیگر invalid_type و رشتهٔ بیش از ۴۰۹۶ بایت input_too_long است.
  2. نرمال‌سازی. ارقام فارسی و عربی به انگلیسی تبدیل می‌شود؛ فاصله، خط تیره و نیم‌فاصله (ZWNJ) حذف و دو سر رشته بریده می‌شود.
  3. قالب. دقیقاً ۱۰ رقم، وگرنه invalid_format.
  4. ارقام تکراری. 0000000000 تا 9999999999 از نظر حساب اتفاقاً درست درمی‌آیند اما کد واقعی نیستند؛ برای همین repeated_digits می‌دهند.
  5. رقم کنترل (قاعدهٔ پیمانهٔ ۱۱ در ادامه)، وگرنه invalid_checksum.

الگوریتم رقم کنترل#

هر یک از نُه رقم اول را در وزنی از ۱۰ تا ۲ ضرب کنید، حاصل‌ها را جمع بزنید و باقیماندهٔ جمع بر ۱۱ را بگیرید. اگر باقیمانده ۰ یا ۱ بود، رقم کنترل برابر باقیمانده است؛ در غیر این صورت برابر ۱۱ منهای باقیمانده.

برای 0499370899: حاصل‌ضرب‌ها ۰، ۳۶، ۷۲، ۶۳، ۱۸، ۳۵، ۰، ۲۴ و ۱۸ است که جمعشان ۲۶۶ می‌شود. باقیمانده ۲۶۶ بر ۱۱ برابر ۲ است؛ پس رقم کنترل باید ۱۱ − ۲ = ۹ باشد و رقم آخر واقعاً ۹ است.

print_r(NationalCode::validate('0499370898')->errors());   // [invalid_checksum]
print_r(NationalCode::validate('1111111111')->errors());   // [repeated_digits]
print_r(NationalCode::validate('12345')->errors());        // [invalid_format]
print_r(NationalCode::validate('abc')->errors());          // [invalid_format]
رشته بماند. کد ملی می‌تواند با صفر شروع شود. NationalCode::validate(499370899) فقط نُه رقم 499370899 را می‌بیند و invalid_format می‌دهد. مقدار را میان ورودی و اعتبارسنج، از جمله در ستون پایگاه داده یا عدد JSON، به عدد صحیح تبدیل نکنید.

ورودی‌های پذیرفته‌شده#

ورودینتیجه
'0499370899'معتبر
'۰۴۹۹۳۷۰۸۹۹' (ارقام فارسی)معتبر
'٠٤٩٩٣٧٠٨٩٩' (ارقام عربی-هندی)معتبر
'049-937-0899'، ' 0499370899 'معتبر؛ جداکننده و فاصله حذف می‌شود
null، []، 1.5invalid_type
12.0به صورت '12' خوانده می‌شود، پس invalid_format
۴۰۹۷ نویسهinput_too_long

فقط فاصله، خط تیره و ZWNJ جداکننده شمرده می‌شوند. اسلش، نقطه و حرف حذف نمی‌شوند و به invalid_format می‌انجامند.

برای گرفتن شکل تمیز بدون اعتبارسنجی از NationalCode::normalize() استفاده کنید:

echo NationalCode::normalize(' ۰۴۹-۹۳۷ ۰۸۹۹ ');   // 0499370899

جزئیات Result#

کلیدنوعمعنا
normalizedرشتهکد پس از نرمال‌سازی (برای invalid_type و input_too_long خالی)
locationآرایه یا nullبرای کد معتبری که پیش‌شمارهٔ آن در جدول هست {province, city}، وگرنه null

کلیدهای خطا: invalid_format، repeated_digits، invalid_checksum، invalid_type، input_too_long. معنای هر کدام در جدول کلیدهای خطا آمده است.

اشارهٔ محل صدور#

سه رقم اول کد ملی پیش‌شماره‌ای است که ثبت احوال تخصیص داده است. NationalCode::getLocation() آن را به استان و شهر نگاشت می‌کند و وقتی کد نامعتبر باشد یا پیش‌شماره در جدول نباشد null برمی‌گرداند:

print_r(NationalCode::getLocation('0499370899'));
// Array ( [province] => تهران [city] => شهرری )

var_dump(NationalCode::getLocation('0499370898'));   // NULL (کد نامعتبر)

$a = NationalCode::validate('0012345679');   // پیش‌شمارهٔ 001
echo json_encode($a->details()['location'], JSON_UNESCAPED_UNICODE);
// {"province":"تهران","city":"تهران مرکزی"}

$b = NationalCode::validate('9991234561');   // رقم کنترل درست، پیش‌شمارهٔ 999 در جدول نیست
var_dump($b->isValid(), $b->details()['location']);   // bool(true)  NULL
اشاره است، نه سند. پیش‌شماره نشان می‌دهد شناسنامه یا کارت اولیه کجا صادر شده، نه محل تولد یا سکونت. بسیاری از افراد کدی دارند که جای دیگری صادر شده و مرز استان‌ها هم پس از صدور تغییر کرده است (برای نمونه کرج زیر تهران آمده). هرگز از محل برای احراز هویت، اصالت یا سکونت استفاده نکنید.
محدودیت شناخته‌شده. ثبت احوال فهرست ماشین‌خوان منتشر نمی‌کند. جدول ۵۴۷ پیش‌شماره دارد و هر مورد فقط وقتی آمده که سه مجموعه‌دادهٔ جامعه بر استان و شهر آن توافق داشته و چهارمی با آن مخالف نبوده باشد. این مجموعه‌ها ریشهٔ مشترک دارند (چند تا از آن‌ها نسخهٔ منتقل‌شده یا مشتق یکدیگرند)؛ پس توافقشان قوی است اما کاملاً مستقل نیست. نبودن پیش‌شماره یعنی ناشناخته، نه نامعتبر. منابع در دقت و داده‌ها آمده است.

اعتبارسنجی چه چیزی را نمی‌گوید#

  • رقم کنترل درست یعنی عدد خوش‌قالب است، نه اینکه آن کد واقعاً صادر شده یا متعلق به فرد مشخصی باشد.
  • اشخاص حقوقی شناسهٔ ۱۱ رقمی جداگانه‌ای دارند. این اعتبارسنج آن را پوشش نمی‌دهد و با invalid_format رد می‌کند.
  • شمارهٔ شناسایی اتباع خارجی (آمایش و مانند آن) طرح دیگری است و پوشش داده نمی‌شود.

استفاده در فرم#

پیام را بر اساس کلید خطا نشان دهید و مقدار نرمال‌شده را ذخیره کنید:

$messages = [
    'invalid_format'   => 'کد ملی باید ۱۰ رقم باشد.',
    'repeated_digits'  => 'این کد ملی معتبر نیست.',
    'invalid_checksum' => 'این کد ملی معتبر نیست.',
];

$result = NationalCode::validate($_POST['national_code'] ?? null);
if (! $result->isValid()) {
    $key = $result->errors()[0];
    echo $messages[$key] ?? 'ورودی نامعتبر است.';
} else {
    $code = $result->details()['normalized'];   // همین مقدار را ذخیره کنید
}

در لاراول از قاعده و ترجمه‌های آماده استفاده کنید؛ اعتبارسنجی و Cast در لاراول را ببینید.
