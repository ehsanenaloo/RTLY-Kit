این کلاس چه می‌کند#

کلاس RtlyKit\Calendar\Hebrew یک مقدار تاریخ‌وزمان تغییرناپذیر در تقویم عبری (یهودی) است. به‌صورت PHP خالص نوشته شده (بدون ext-calendar) و تقویم حسابی ثابت را پیاده می‌کند: مولاد تیشری، چهار تعویق دهییوت و سال‌هایی با 353/354/355 روز (عادی) و 383/384/385 روز (کبیسه). مثل دو تقویم دیگر یک لحظهٔ DateTimeImmutable را در خود دارد و قرارداد CalendarDate را پیاده می‌کند (تبدیل و مقایسهٔ تاریخ‌ها).

<?php
require 'vendor/autoload.php';

use RtlyKit\Calendar\Hebrew;
use RtlyKit\Exceptions\InvalidDateException;
use function RtlyKit\hebrew_date;   // تابع کمکی فضای‌نام‌دار؛ همان Hebrew::make()

$utc = new DateTimeZone('UTC');
محدودیت شناخته‌شده. روز عبری در واقع از غروب آغاز می‌شود. این کلاس، مانند تقویم‌های دیگر کتابخانه، تاریخ را در نیمه‌شب مدنی عوض می‌کند؛ پس مثلاً ساعتِ عصرِ شب عید در عمل به تاریخ عبریِ روز بعد تعلق دارد ولی اینجا هنوز روز قبل است. کلاس تعطیلات، پاراشا یا شمارش عومر را هم محاسبه نمی‌کند.

شمارهٔ ماه‌ها#

ماه‌ها با جایگاه ترتیبی در سال، از تیشری (آغاز سال مدنی) شماره‌گذاری می‌شوند. در سال کبیسه آدار اول و آدار دوم دو ماه جدا هستند:

  • ماه‌های 1 تا 5 همیشه تیشری، حشوان، کسلو، طوت و شواط‌اند.
  • سال عادی: 6 = آدار، 7 = نیسان، 8 = ایار، 9 = سیوان، 10 = تموز، 11 = آو، 12 = الول.
  • سال کبیسه: 6 = آدار اول، 7 = آدار دوم، 8 = نیسان، 9 = ایار، 10 = سیوان، 11 = تموز، 12 = آو، 13 = الول.
شماره‌گذاری Hebcal نیست. این روش با Hebcal (نیسان = 1) و با ext-calendar پی‌اچ‌پی فرق دارد. الول در سال عادی ماه 12 و در سال کبیسه ماه 13 است و نیسان ماه 7 یا 8. شمارهٔ ماه را همیشه از خود Hebrew بگیرید (getMonth()، monthName()، monthsInYear()) و از جدول کتابخانهٔ دیگر کپی نکنید.
foreach ([5784, 5785] as $y) {
    $a = [];
    for ($m = 1; $m <= Hebrew::monthsInYear($y); $m++) {
        $a[] = $m.':'.Hebrew::monthName($y, $m).'('.Hebrew::daysInMonth($y, $m).')';
    }
    echo $y, ' ', implode(' ', $a), "\n";
}
// 5784 1:Tishrei(30) 2:Cheshvan(29) 3:Kislev(29) 4:Tevet(29) 5:Shevat(30) 6:Adar I(30) 7:Adar II(29) 8:Nisan(30) 9:Iyar(29) 10:Sivan(30) 11:Tammuz(29) 12:Av(30) 13:Elul(29)
// 5785 1:Tishrei(30) 2:Cheshvan(30) 3:Kislev(30) 4:Tevet(29) 5:Shevat(30) 6:Adar(29) 7:Nisan(30) 8:Iyar(29) 9:Sivan(30) 10:Tammuz(29) 11:Av(30) 12:Elul(29)

Hebrew::monthName($year, $month, $locale = 'en') زبان‌های en، he و fa را پشتیبانی می‌کند (زبان ناشناخته به en برمی‌گردد)؛ در سال عادی، جایگاه 6 «آدار» ساده است.

ساخت تاریخ#

متد Hebrew::create($year, $month, $day, $hour = 0, $minute = 0, $second = 0, $timezone = null) تاریخ را با طول واقعی همان ماه در همان سال اعتبارسنجی می‌کند (حشوان و کسلو بین 29 و 30 روز تغییر می‌کنند).

$e = Hebrew::create(5785, 1, 1, 0, 0, 0, $utc);

echo $e;                                   // 5785/01/01 00:00:00
echo $e->toGregorian()->format('Y-m-d');   // 2024-10-03
echo Hebrew::create(5785, 7, 15, 0, 0, 0, $utc)->toGregorian()->format('Y-m-d');  // 2025-04-13  (۱۵ نیسان 5785)
echo Hebrew::create(5786, 1, 10, 0, 0, 0, $utc)->toGregorian()->format('Y-m-d l'); // 2025-10-02 Thursday

متد Hebrew::make($time = null, $timezone = null) این ورودی‌ها را می‌پذیرد: DateTimeInterface، هر CalendarDate، زمان یونیکس، رشته یا null؛ تابع کمکی آن hebrew_date() است. اگر نمونهٔ Hebrew بدهید همان بدون تغییر برمی‌گردد.

echo Hebrew::make('2025-10-07', $utc);                       // 5786/01/15 00:00:00
echo hebrew_date('2025-10-07')->format('Y/m/d F');           // 5786/01/15 Tishrei
echo Hebrew::make('5785/01/10', $utc);                       // 5785/01/10 00:00:00
echo Hebrew::make('0001-09-06')->format('Y/m/d');            // 3762/01/01

معنای رشته#

  1. ارقام فارسی و عربی به انگلیسی تبدیل می‌شوند، رشته تریم می‌شود و رشتهٔ خالی InvalidDateException پرتاب می‌کند.
  2. رشته‌ای به شکل Y/m/d یا Y-m-d (اختیاری H:i[:s]) با سال 3000 یا بیشتر تاریخ عبری خوانده می‌شود و ماه، همان شمارهٔ ترتیبی بالاست. (آستانه برعکس جلالی و هجری است که سال کمتر از 1700 را از خود می‌دانند.)
  3. هر رشتهٔ دیگر میلادی یا متن آزاد پارس می‌شود.

پس '5785/01/10' عبری است، '2025-10-07' میلادی است، و '3000/01/01' سال عبری 3000 خوانده می‌شود که کمتر از حداقل پشتیبانی‌شده است و خطای Invalid Hebrew date: 3000/1/1 می‌دهد.

بازهٔ پشتیبانی‌شده و خطاها#

سال‌های عبری از Hebrew::MIN_YEAR = 3762 تا Hebrew::MAX_YEAR = 13759 پشتیبانی می‌شوند؛ دقیقاً سال‌هایی که درون سال‌های میلادی 1 تا 9999 قرار می‌گیرند: اولین روز اول تیشری 3762 (0001-09-06) و آخرین روز، آخرین روز الول 13759 (9999-11-03). هر چیز بیرون از آن InvalidDateException پرتاب می‌کند؛ isValid() به‌جای پرتاب false برمی‌گرداند.

foreach ([[3761, 1, 1], [13760, 1, 1], [5785, 13, 1], [5785, 3, 31]] as [$y, $m, $d]) {
    try { Hebrew::create($y, $m, $d); }
    catch (InvalidDateException $x) { echo $x->getMessage(), "\n"; }
}
// Invalid Hebrew date: 3761/1/1
// Invalid Hebrew date: 13760/1/1
// Invalid Hebrew date: 5785/13/1       (5785 سال عادی است: ۱۲ ماه)
// Invalid Hebrew date: 5785/3/31

echo Hebrew::create(5784, 13, 1) instanceof Hebrew ? 'ok' : '';   // ok  (5784 سال کبیسه است)

try { Hebrew::make('0001-01-01'); }
catch (InvalidDateException $x) { echo $x->getMessage(); }
// Date out of the supported Hebrew range (3762..13759): 3761

کمکی‌های حسابیِ daysInYear()، daysInMonth() و monthName() سال‌های 1 تا 13759 را می‌پذیرند (سال 0 خطای Hebrew year out of the supported range: 0 می‌دهد)؛ فقط ساخت تاریخ از حداقل 3762 استفاده می‌کند.

خواندن مقدارها#

گیرنده‌ها همان قرارداد هستند (getYear()، getMonth()، getDay()، اجزای زمان، getTimestamp()، getTimezone()، toGregorian()، toDateString()، toDateTimeString()). getMonth() همان شمارهٔ ترتیبی ماه است.

شمارهٔ روز هفته#

getDayOfWeek() و توکن w یکشنبه‌محور هستند: 0 = یکشنبه تا 6 = شنبه (مثل هجری و PHP، برخلاف جلالی). N شمارهٔ ISO است (دوشنبه = 1).

echo $e->getDayOfWeek();   // 4   (اول تیشری 5785 پنجشنبه بود)
foreach (range(0, 6) as $i) { echo $e->addDays($i)->getDayOfWeek(); }  // 4560123

قالب‌بندی#

format($pattern = 'Y/m/d H:i:s', $locale = 'en') با $locale برابر en، he یا fa. ارقام همیشه لاتین‌اند. بک‌اسلش نویسهٔ بعدی را بدون تفسیر می‌نویسد.

echo $e->format('l j F Y');         // Thursday 1 Tishrei 5785
echo $e->format('l j F Y', 'he');   // חמישי 1 תשרי 5785
echo $e->format('l j F Y', 'fa');   // پنجشنبه 1 تشری 5785

echo Hebrew::create(5784, 6, 15, 0, 0, 0, $utc)->format('j F');   // 15 Adar I
echo Hebrew::create(5784, 7, 15, 0, 0, 0, $utc)->format('j F');   // 15 Adar II

جابه‌جایی و برش#

متدها همان جلالی است. دو قاعدهٔ ویژهٔ عبری اهمیت دارد:

  • ماه‌ها ترتیبی شمرده می‌شوند و آدار اول و دوم دو ماه جدا هستند؛ روز به طول ماهِ مقصد کاهش می‌یابد. حجم کار محدود است (چرخه‌های کامل 19 ساله به‌اضافهٔ حداکثر 19 گام سالانه) و به بزرگیِ $months بستگی ندارد.
  • سال‌ها ماهِ «همان» را حفظ می‌کنند: رفتن از سال کبیسه به عادی، آدار اول و دوم را به آدار می‌برد؛ رفتن از عادی به کبیسه، آدار را به آدار دوم می‌برد.
$adar1 = Hebrew::create(5784, 6, 15, 0, 0, 0, $utc);
echo $adar1->addMonths(1)->format('Y/m/d F');                                  // 5784/07/15 Adar II
echo Hebrew::create(5784, 7, 15, 0, 0, 0, $utc)->addYears(1)->format('Y/m/d F'); // 5785/06/15 Adar
echo Hebrew::create(5785, 2, 29, 0, 0, 0, $utc)->addMonths(1);                   // 5785/03/29 00:00:00
echo Hebrew::create(5785, 5, 30, 0, 0, 0, $utc)->addMonths(1)->format('Y/m/d F'); // 5785/06/29 Adar  (کاهش روز)
echo $e->endOfMonth();   // 5785/01/30 23:59:59
echo $e->endOfYear();    // 5785/12/29 23:59:59

مقایسه و اندازه‌گیری#

مقایسه روی لحظه‌ها انجام می‌شود و هر تقویمی را می‌پذیرد. diffInMonths() ماه کامل عبری می‌شمارد (آدار اول و دوم جدا شمرده می‌شوند)؛ diffInYears() بر پایهٔ سالگرد است (سال عبری 12 یا 13 ماه دارد، پس «ماه تقسیم بر 12» نیست).

echo Hebrew::create(5784, 1, 1, 0, 0, 0, $utc)->diffInMonths(Hebrew::create(5785, 1, 1, 0, 0, 0, $utc)); // 13
echo Hebrew::create(5780, 3, 3, 0, 0, 0, $utc)->diffInYears(Hebrew::create(5785, 3, 2, 0, 0, 0, $utc));  // 4

محاسبات تقویمی#

متدخروجی
Hebrew::isValid($y, $m, $d)bool
Hebrew::isLeapYear($y)true برای سال‌های 3، 6، 8، 11، 14، 17 و 19 از چرخهٔ 19 ساله
Hebrew::monthsInYear($y)12 یا 13
Hebrew::daysInYear($y)353، 354، 355، 383، 384 یا 385
Hebrew::daysInMonth($y, $m)29 یا 30؛ برای ماهِ بیش از تعداد ماه‌های سال خطا می‌دهد
Hebrew::gregorianToHebrew($gy, $gm, $gd)[سال, ماه ترتیبی, روز]
Hebrew::hebrewToGregorian($hy, $hm, $hd)[سال, ماه, روز]
 
echo (Hebrew::isLeapYear(5784) ? 'leap' : 'regular'), ' ', (Hebrew::isLeapYear(5785) ? 'leap' : 'regular'); // leap regular
echo Hebrew::daysInYear(5784), ' ', Hebrew::daysInYear(5785), ' ', Hebrew::daysInYear(5786);             // 383 355 354
echo json_encode(Hebrew::gregorianToHebrew(2025, 10, 3));   // [5786,1,11]
echo json_encode(Hebrew::hebrewToGregorian(5786, 1, 1));    // [2025,9,23]
