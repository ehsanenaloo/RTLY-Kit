تبدیل عدد به حروف#

NumberToWords::convert() یک عدد صحیح را به حروف می‌نویسد. زبان پیش‌فرض فارسی (fa) است و هر عدد صحیح زیر 1021 را پوشش می‌دهد.

<?php
require 'vendor/autoload.php';

use RtlyKit\Number\NumberToWords;
use function RtlyKit\number_to_words;

echo NumberToWords::convert(0), "\n";        // صفر
echo NumberToWords::convert(21), "\n";       // بیست و یک
echo NumberToWords::convert(115), "\n";      // صد و پانزده
echo NumberToWords::convert(1001), "\n";     // یک هزار و یک
echo NumberToWords::convert(12345), "\n";    // دوازده هزار و سیصد و چهل و پنج
echo NumberToWords::convert(-45), "\n";      // منفی چهل و پنج
echo number_to_words(2000000000), "\n";      // دو میلیارد
echo NumberToWords::convert(1234567), "\n";
// یک میلیون و دویست و سی و چهار هزار و پانصد و شصت و هفت

بخش‌ها با « و » به هم وصل می‌شوند و واژهٔ مقیاس بعد از هر گروه می‌آید: «هزار» (103)، «میلیون» (106)، «میلیارد» (109)، «تریلیون» (1012)، «کوادریلیون» (1015) و «کوینتیلیون» (1018). گروهی که برابر ۱ باشد «یک» خود را نگه می‌دارد (۱۰۰۰ می‌شود «یک هزار»؛ برای خواندن «هزار» تنها از fromWords() در ادامه استفاده کنید). گروه‌های صفر نادیده گرفته می‌شوند.

ورودی پذیرفته‌شده#

نوع پارامتر int|float|string است:

  • int: کل بازهٔ PHP از جمله PHP_INT_MAX کار می‌کند: «نه کوینتیلیون و دویست و بیست و سه کوادریلیون ...».
  • float: باید متناهی و صحیح باشد. 3.0 می‌شود «سه»؛ 1.5 به جای قطع بی‌صدای اعشار استثنا می‌اندازد.
  • string: علامت اختیاری و ارقام از هر دستهٔ رقمی. ویرگول، ٬ و فاصله حذف می‌شود؛ پس عددی که از فرم کپی شده کار می‌کند. رشته می‌تواند از int پی‌اچ‌پی بلندتر باشد، تا ۲۱ رقم پس از حذف صفرهای ابتدایی.
echo NumberToWords::convert('۱۲۳٬۴۵۶'), "\n";        // صد و بیست و سه هزار و چهارصد و پنجاه و شش
echo NumberToWords::convert('1,000,000'), "\n";      // یک میلیون
echo NumberToWords::convert('+7'), "\n";             // هفت
echo NumberToWords::convert('-0'), "\n";             // صفر
echo NumberToWords::convert('999999999999999999999'), "\n";
// نهصد و نود و نه کوینتیلیون و نهصد و نود و نه کوادریلیون ... و نهصد و نود و نه

خطاها#

ورودی نامعتبر InvalidNumberException (زیرکلاس RtlyKitException) پرتاب می‌کند. کد پایدار را با getErrorCode() بخوانید:

ورودیکد خطا
1.5، '12a'، ''invalid_number
NAN، INFnon_finite_number
رشتهٔ بلندتر از ۴۰۹۶ بایتinput_too_long
1e21، '1000000000000000000000' (۲۲ رقم)number_too_large
 
try {
    NumberToWords::convert('1000000000000000000000');
} catch (\RtlyKit\Exceptions\InvalidNumberException $e) {
    echo $e->getMessage(), ' [', $e->getErrorCode()->value, "]\n";
    // Number is too large (limit is 10^21 - 1). [number_too_large]
}

برای گرفتن همهٔ استثناهای کتابخانه با یک نوع، مدیریت خطا را ببینید.

عربی#

برای عربی فصیح، 'ar' را آرگومان دوم بدهید. زبان بر پایهٔ دو حرف اول و بدون حساسیت به بزرگی و کوچکی حروف تطبیق داده می‌شود؛ پس 'ar_SA' و 'AR' کار می‌کنند و برای فارسی 'fa_IR' هم.

echo NumberToWords::convert(11, 'ar'), "\n";        // أحد عشر
echo NumberToWords::convert(21, 'ar'), "\n";        // واحد وعشرون
echo NumberToWords::convert(200, 'ar'), "\n";       // مئتان
echo NumberToWords::convert(3000, 'ar'), "\n";      // ثلاثة آلاف
echo NumberToWords::convert(2000000, 'ar'), "\n";   // مليونان
echo NumberToWords::convert(1002003, 'ar'), "\n";   // مليون وألفان وثلاثة
echo NumberToWords::convert(-7, 'ar'), "\n";        // سالب سبعة

خروجی عربی از این قاعده‌ها پیروی می‌کند و محدودیت‌هایش واقعی است:

  • بازه: قدرمطلق عدد باید زیر 109 باشد (تا ۹۹۹٬۹۹۹٬۹۹۹). عدد بزرگ‌تر number_too_large می‌اندازد. مبدل برای ۰ تا ۹۹۹٬۹۹۹٬۹۹۹ و اعداد منفی آزموده شده است.
  • فقط صورت شمارشی مذکر. مطابقت جنس با معدود، حالت‌های اعرابی و تنوین وجود ندارد.
  • گروه‌های مرکب ساده‌اند. گروهی مثل ۱۰۲ در ۱۰۲٬۰۰۰ از صورت مرکب معمولی («مئة واثنان ألف») استفاده می‌کند، بدون قاعده‌های ویژهٔ حالت اضافه که بعضی راهنمای نگارش لازم می‌دانند.
  • عدد منفی با «سالب» شروع می‌شود.
محدودیت شناخته‌شده. خروجی عربی را عدد خوانا به حروف بدانید، نه متن حقوقی یا حروف‌چینی‌شدهٔ مناسب چک. اگر جنس یا حالت دستوری معدود مهم است، عبارت را دستی بازبینی کنید.

زبان پشتیبانی‌نشده UnsupportedLocaleException با کد unsupported_locale می‌اندازد:

try {
    NumberToWords::convert(5, 'en');
} catch (\RtlyKit\Exceptions\UnsupportedLocaleException $e) {
    echo $e->getMessage(), "\n";   // Unsupported locale 'en' (use 'fa' or 'ar').
}

از حروف به عدد#

NumberToWords::fromWords() معکوس تبدیل فارسی برای شکل‌هایی است که convert() می‌سازد. اگر مقدار در int پی‌اچ‌پی جا شود int و در غیر این صورت رشتهٔ ارقام برمی‌گرداند.

var_dump(NumberToWords::fromWords('بیست و سه'));                 // int(23)
var_dump(NumberToWords::fromWords('منفی چهل و دو'));             // int(-42)
var_dump(NumberToWords::fromWords('هزار و یک'));                 // int(1001)
var_dump(NumberToWords::fromWords('دو میلیون و سیصد هزار و پنج')); // int(2300005)

// رفت‌وبرگشت در کل بازه:
var_dump(NumberToWords::fromWords(NumberToWords::convert(PHP_INT_MAX)));
// int(9223372036854775807)
var_dump(NumberToWords::fromWords(NumberToWords::convert('999999999999999999999')));
// string(21) "999999999999999999999"

چگونه حروف خوانده می‌شود#

  • ابتدا ورودی نرمال می‌شود: صورت‌های عربی حروف به فارسی تبدیل می‌شود («ك» به «ک»، «ي» به «ی»)، ZWNJ فاصله حساب می‌شود و فاصله‌های اضافه نادیده گرفته می‌شود.
  • «منفی» در ابتدا نتیجه را منفی می‌کند؛ «منفی صفر» برابر 0 است.
  • واژهٔ مقیاسِ بدون عدد پیش از آن یعنی یک؛ پس «هزار» برابر ۱۰۰۰ است.
  • مقیاس‌ها باید نزولی باشند: «هزار هزار» یا «هزار میلیون» استثنا می‌اندازد.
  • هیچ گروهی نباید از ۹۹۹ بیشتر شود.
  • واژهٔ «و» هر جا باشد نادیده گرفته می‌شود.
try {
    NumberToWords::fromWords('یکصد');
} catch (\RtlyKit\Exceptions\InvalidNumberException $e) {
    echo $e->getMessage(), ' [', $e->getErrorCode()->value, "]\n";
    // Unknown number word 'یکصد'. [invalid_number_words]
}

خطاها کد invalid_number_words دارند (واژهٔ ناشناخته، دنبالهٔ بدساخت، مقیاس‌های نامرتب، متن خالی) یا برای متن بیش از ۴۰۹۶ بایت input_too_long.

خواننده سهل‌گیر است. fromWords() مقدارهای داخل هر گروه را بدون بررسی ترتیب طبیعی واژه‌ها جمع می‌زند؛ بنابراین عبارت‌های غیرمعمولی مثل «دو صد» (۱۰۲) یا «و»ی زائد در انتها پذیرفته می‌شود. این تابع خوانندهٔ خروجی convert() و عددهای معمولی دست‌نویس است، نه بررسی‌کنندهٔ دستور زبان؛ متن نامطمئن را خودتان اعتبارسنجی کنید. فقط شکل فارسی خوانده می‌شود: واژه‌های عربی خروجی convert($n, 'ar') و ترتیبی‌هایی مثل «سی‌ام» فهمیده نمی‌شود و استثنا می‌اندازد. املای چسبیدهٔ «یکصد» هم ناشناخته است.
