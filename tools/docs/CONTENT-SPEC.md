# Docs site content spec (shared by the generator and the content authors)

The public guide site lives in `docs/` (static HTML, no build step for readers) and is GENERATED by
`tools/docs/build.php` from the fragments in `tools/docs/content/<lang>/<slug>.html`
(`<lang>` = `fa` | `en` | `ar`). Never hand-edit generated files in `docs/`.

## Fragment format
Each fragment starts with an HTML comment of `key: value` lines, then the body HTML:

```
<!--
title: Jalali calendar
description: One or two sentences, shown as the lead paragraph, card text and meta description.
group: calendars
order: 10
-->
<h2 id="make">Creating dates</h2>
<p>...</p>
```

- Body starts at `<h2>` (the generator renders the `<h1>` and lead from title/description and builds the table of contents from `h2`/`h3`; every `h2`/`h3` needs a unique `id`).
- Allowed markup: `h2 h3 p ul ol li table(thead/tbody) pre><code class="language-php|bash|json|text"> code strong em a kbd blockquote`, and callouts `<div class="note">`, `<div class="warn">`, `<div class="known">` (known limitation) each starting with `<strong>Label.</strong>`.
- Internal links: `<a href="slug.html">` (same language, same folder) or `<a href="slug.html#id">`. Link only to slugs listed below. No external resources, scripts, images or fonts (external hyperlinks to sources/GitHub are fine).
- Code samples must be runnable and VERIFIED in Docker (`docker compose -f tools/docker-compose.yml run --rm -T php php file.php` with `require '/app/vendor/autoload.php';`) and use `use function RtlyKit\jdate;` style imports (helpers are namespaced; `Globals::register()` is opt-in). Show the real output in a comment. Do not invent output.
- Persian text is the primary voice (natural, correct Persian; technical identifiers stay in English/LTR, wrap them in `<code>`); English must be a faithful equivalent, not a loose rewrite. Arabic (`ar`, right-to-left) is Modern Standard Arabic, also a faithful translation of the English fragment: same ids, same code and outputs (prose comments in code are translated), technical identifiers in `<code>`, Western digits 0-9. Same ASCII ids in all three languages.
- Truth sources: `src/` (code is the authority), `README.md`, `CHANGELOG.md`, `UPGRADE.md`, `resources/data/SOURCES.md`. Honest accuracy claims only (state limitations and unverified areas plainly).
