ارقام

کلاس RtlyKit\Number\Digits میان سه دستهٔ رقمی نرم‌افزارهای ایرانی تبدیل می‌کند: انگلیسی (0-9)، فارسی (۰-۹، از U+06F0 تا U+06F9) و عربی-هندی (٠-٩، از U+0660 تا U+0669). این کلاس فقط جایگزینی رشته‌ای است: هرگز استثنا نمی‌اندازد، به نویسه‌های دیگر دست نمی‌زند و جداکنندهٔ اعشار یا هزارگان را تغییر نمی‌دهد.

<?php
require 'vendor/autoload.php';

use RtlyKit\Number\Digits;

echo Digits::toPersian('Tel 0912 / 2024'), "\n";   // Tel ۰۹۱۲ / ۲۰۲۴
echo Digits::toPersian(1234.5), "\n";              // ۱۲۳۴.۵
echo Digits::toArabic(2026), "\n";                 // ٢٠٢٦
echo Digits::toEnglish('۱۲۳ ٤٥٦ abc'), "\n";        // 123 456 abc
echo Digits::arabicToPersian('٠١٢ 345'), "\n";      // ۰۱۲ 345

convert()

متد convert() ابتدا به انگلیسی نرمال می‌کند و بعد دستهٔ مقصد را می‌سازد. نام مقصد به بزرگی و کوچکی حروف حساس نیست: persian، fa و farsi ارقام فارسی می‌دهند؛ arabic و ar ارقام عربی-هندی؛ هر چیز دیگر، از جمله غلط املایی، انگلیسی.

echo Digits::convert('۱۲۳', 'ar'), "\n";        // ١٢٣
echo Digits::convert('123', 'fa'), "\n";        // ۱۲۳
echo Digits::convert('٣٤٥', 'FARSI'), "\n";     // ۳۴۵
echo Digits::convert('۱۲۳', 'x'), "\n";         // 123
عدد به‌عنوان ورودی. toPersian() و toArabic() int و float را هم می‌پذیرند و با تبدیل ساده به رشته ((string)) برمی‌گردانند؛ پس ممیز اعشار همان نقطهٔ لاتین می‌ماند (۱۲۳۴.۵) و جداکنندهٔ هزارگان ندارد. برای عددهایی که کاربر می‌بیند از Format::withSeparator() در ادامه استفاده کنید. توابع کمکی to_persian_digits()، to_english_digits()، to_persian() و to_english() این متدها را پوشش می‌دهند؛ توابع کمکی و نام‌های سراسری را ببینید.

اعتبارسنج‌ها برای نرمال‌سازی از Digits::toEnglish() استفاده می‌کنند؛ پس کاربر می‌تواند با هر دستهٔ رقمی تایپ کند. نرمال‌سازی را ببینید.

قالب‌بندی عدد

Format::withSeparator() عدد را با جداکنندهٔ هزارگان و ارقام فارسی قالب‌بندی می‌کند. به طور پیش‌فرض از جداکنندهٔ هزارگان عربی ٬ (U+066C) و ممیز اعشار ٫ (U+066B) استفاده می‌کند؛ نویسه‌هایی که تایپوگرافی فارسی توصیه می‌کند. هرگز گرد نمی‌کند.

use RtlyKit\Number\Format;

echo Format::withSeparator(1234567), "\n";            // ۱٬۲۳۴٬۵۶۷
echo Format::withSeparator('1,234,567.5'), "\n";      // ۱٬۲۳۴٬۵۶۷٫۵
echo Format::withSeparator('۱٬۲۳۴٫۵'), "\n";          // ۱٬۲۳۴٫۵
echo Format::withSeparator('0001234'), "\n";          // ۱٬۲۳۴
echo Format::withSeparator('+12345'), "\n";           // ۱۲٬۳۴۵
echo Format::withSeparator(1.0), "\n";                // ۱

چه چیزی می‌پذیرد

  • int، float متناهی، یا رشتهٔ عددی با علامت اختیاری، ارقام از هر سه دسته و کسر اختیاری.
  • در رشته‌ها این‌ها به‌عنوان جداکنندهٔ گروه حذف می‌شوند: ,، ٬ (U+066C)، فاصلهٔ معمولی و فاصلهٔ بدون شکست. ممیز اعشار عربی ٫ (U+066B) به‌عنوان نقطهٔ اعشار خوانده می‌شود و . هم نقطهٔ اعشار است.
  • صفرهای ابتدای بخش صحیح و + ابتدایی حذف می‌شود و - ابتدایی می‌ماند.

هر چیزی که پس از این پاک‌سازی عدد اعشاری ساده نباشد InvalidNumberException پرتاب می‌کند: 'abc'، رشتهٔ خالی، نمای علمی در رشته ('1e5') و NaN یا INF. استثنا یک کد خطای پایدار دارد (invalid_number، non_finite_number، input_too_long) که با getErrorCode() خوانده می‌شود؛ مدیریت خطا را ببینید.

جداکنندهٔ سفارشی

آرگومان دوم و سوم جداکنندهٔ هزارگان و اعشار را عوض می‌کنند. ارقام همچنان فارسی می‌شوند:

echo Format::withSeparator(1234567, ','), "\n";            // ۱,۲۳۴,۵۶۷
echo Format::withSeparator(1234567.5, ',', '.'), "\n";     // ۱,۲۳۴,۵۶۷.۵

برای ارقام انگلیسی نتیجه را با Digits::toEnglish() برگردانید.

اعشاری و دقت

float تا ۱۵ رقم اعشار باز می‌شود و صفرهای انتها حذف می‌گردد؛ پس نویز نمایش دودویی ممکن است دیده شود. اگر عدد اعشاری دقیق لازم دارید رشته بدهید:

echo Format::withSeparator(0.1 + 0.2), "\n";       // ۰٫۳
echo Format::withSeparator(-1234567.891), "\n";    // -۱٬۲۳۴٬۵۶۷٫۸۹۱۰۰۰۰۰۰۰۶۱۴۶۷
echo Format::withSeparator('-1234567.891'), "\n";  // -۱٬۲۳۴٬۵۶۷٫۸۹۱
پول و مقدارهای بزرگ. مبلغ‌ها را از ابتدا تا انتها به صورت رشته یا عدد صحیح (ریال) نگه دارید. اعشاری بیشتر کسرها را دقیق نشان نمی‌دهد و قالب‌بند همان ارقامی را بازتولید می‌کند که float واقعاً دارد.

دقیقاً ۱۰۰۰ رقم به‌طور عادی قالب‌بندی می‌شود. همهٔ سقف‌ها در یک جدول در سقف‌ها آمده است. تابع کمکی format_number() همان Format::withSeparator() با مقدارهای پیش‌فرض است.

عدد ترتیبی

Format::ordinal() واژهٔ ترتیبی فارسی را برای یک عدد صحیح نامنفی برمی‌گرداند. ابتدا با NumberToWords عدد اصلی را به حروف می‌نویسد (عدد به حروف) و سپس قاعدهٔ پسوند را اعمال می‌کند:

  • ۱ استثنای «اول» است.
  • عدد اصلی که به «سه» ختم شود «سوم» می‌شود؛ ۲۳ و ۳۳ هم همین‌طورند.
  • عدد اصلی که به «ی» ختم شود (مثل «سی») نیم‌فاصله و «ام» می‌گیرد.
  • بقیه فقط «م» می‌گیرند.
echo Format::ordinal(1), "\n";     // اول
echo Format::ordinal(2), "\n";     // دوم
echo Format::ordinal(3), "\n";     // سوم
echo Format::ordinal(21), "\n";    // بیست و یکم
echo Format::ordinal(23), "\n";    // بیست و سوم
echo Format::ordinal(30), "\n";    // سی‌ام
echo Format::ordinal(33), "\n";    // سی و سوم
echo Format::ordinal(100), "\n";   // صدم
echo Format::ordinal(1000), "\n";  // یک هزارم
echo Format::ordinal(0), "\n";     // صفرم
echo Format::ordinal(3.0), "\n";   // سوم

عدد اعشاری صحیح مثل 3.0 پذیرفته می‌شود. عدد منفی، کسر (2.5) و اعشاری نامتناهی InvalidNumberException می‌اندازند (invalid_number، و برای INF و NaN کد non_finite_number). تابع کمکی آن ordinal() است.

واژه، نه رقم. ordinal() واژهٔ کامل را برمی‌گرداند و شکل کوتاه عددی نمی‌سازد؛ اگر لازم دارید خودتان با Digits::toPersian() بسازید.
