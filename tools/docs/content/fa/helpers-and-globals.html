چرا توابع کمکی در فضای نام‌اند

نام‌هایی مانند is_mobile()، ordinal() یا to_english() کوتاه و عمومی‌اند. PHP راهی برای «بازنویسی» تابع سراسری ندارد: اگر دو بسته (یا برنامهٔ شما و یک بسته) نام سراسری یکسانی تعریف کنند، تعریف دوم خطای مرگبار است. کتابخانه‌ای که بی‌قید‌وشرط تابع سراسری تعریف کند ممکن است برنامه‌ای را که تا پیش از نصب سالم بود از کار بیندازد.

RTLY-Kit این مشکل را در طراحی حل کرده است:

  • هر ۲۷ تابع کمکی در فضای نام RtlyKit تعریف شده‌اند. Composer آن‌ها را خودکار بارگیری می‌کند و هرگز با چیزی برخورد نمی‌کنند.
  • نام‌های کوتاه سراسری اختیاری هستند و با \RtlyKit\Globals::register() فعال می‌شوند که فقط نام‌های آزاد را تعریف می‌کند.
  • سرویس‌پرووایدر لاراول هم تابع سراسری ثبت نمی‌کند. راه‌اندازی لاراول را ببینید.

استفاده از توابع

آنچه لازم دارید با use function وارد کنید و با نام کوتاه صدا بزنید. یا با نام کامل صدا بزنید:

use function RtlyKit\jdate;
use function RtlyKit\is_national_code;

echo jdate('2025-03-21')->format('Y/m/d');       // 1404/01/01
var_dump(is_national_code('0013542419'));         // bool(true)
echo \RtlyKit\to_persian_digits(1404);            // ۱۴۰۴

// چند تابع با هم (group use در PHP):
use function RtlyKit\{hdate, hebrew_date, number_to_words};
echo hdate('2025-03-21')->format('Y/m/d');       // 1446/09/21
echo hebrew_date('2025-03-21')->format('Y/m/d'); // 5785/06/21
echo number_to_words(1404);                       // یک هزار و چهارصد و چهار

این توابع پوشش نازکی هستند: هرکدام کلاس متناظر را صدا می‌زند؛ هر وقت کنترل بیشتری خواستید (مثلاً Jalali::create() با منطقهٔ زمانی) خود کلاس را به کار ببرید.

نام‌های سراسری اختیاری: Globals::register()

اگر نام‌های کوتاه سراسری را ترجیح می‌دهید (مثلاً در کد قدیمی، موتور قالب یا اسکریپت)، یک بار در بوت‌استرپ این را صدا بزنید:

$skipped = \RtlyKit\Globals::register();

تضمین‌ها:

  • فقط نام‌های آزاد تعریف می‌شوند. نامی فقط وقتی تعریف می‌شود که هیچ تابعی با آن نام نباشد. تابع موجود هرگز بازنویسی نمی‌شود.
  • موارد ردشده را گزارش می‌دهد. مقدار بازگشتی list<string> از نام‌هایی است که چون تابع دیگری از آن‌ها استفاده می‌کرد تعریف نشدند. فهرست خالی یعنی همه ثبت شدند.
  • هرگز استثنا پرتاب نمی‌کند و در هیچ شرایطی خطای تعریف مجدد نمی‌دهد.
  • خودتوان (idempotent) است. هر چند بار صدا بزنید فرقی نمی‌کند. نامی که تعریف قبلیِ خود RTLY-Kit باشد ردشده گزارش نمی‌شود، پس فراخوانی دوم همان فهرست اول را برمی‌گرداند.
  • توابع فضای‌نامی همیشه کار می‌کنند، چه نام سراسری ردشده باشد چه نه.
  • ثابت \RtlyKit\Globals::NAMES هر ۲۷ نام را فهرست می‌کند.

نمونهٔ برخورد نام

برنامه از قبل is_mobile() خودش را دارد (بررسی user-agent). بسته آن را خراب نمی‌کند، بازنویسی نمی‌کند و به شما خبر می‌دهد:

require 'vendor/autoload.php';

// برنامه از قبل تابع سراسری هم‌نام دارد.
function is_mobile(string $ua): bool { return str_contains($ua, 'Mobi'); }

$skipped = \RtlyKit\Globals::register();
var_dump($skipped);
// array(1) { [0]=> string(9) "is_mobile" }

var_dump(is_mobile('Mozilla/5.0 (iPhone) Mobile'));   // bool(true)   تابع خودِ برنامه
var_dump(\RtlyKit\is_mobile('09123456789'));           // bool(true)   بررسی شمارهٔ موبایل ایران، همیشه در دسترس
echo jdate('2025-03-21')->format('Y/m/d'), "\n";       // 1404/01/01   نام آزاد: به‌صورت سراسری ثبت شد
var_dump(\RtlyKit\Globals::register());                // خودتوان: همان فهرست، array(1) { [0]=> string(9) "is_mobile" }

سیاست معقول این است که فهرست را لاگ کنید و ادامه دهید:

$skipped = \RtlyKit\Globals::register();
if ($skipped !== []) {
    error_log('RTLY-Kit globals skipped: ' . implode(', ', $skipped));
}
نکته. تعریف‌های تابعِ سطح بالای یک فایل PHP پیشاپیش ثبت (hoist) می‌شوند؛ پس تابع سراسری‌ای که در همان فایلِ فراخوانی، پایین‌تر تعریف شده باشد هم «از قبل تعریف‌شده» حساب می‌شود. اگر نامی برایتان مهم است آن را پیش از register() تعریف کنید یا فقط به تابع فضای‌نامی تکیه کنید.

کدام سبک را انتخاب کنم؟

  • کتابخانه‌ها و برنامه‌های جدید: importهای فضای‌نامی (use function RtlyKit\jdate;). صریح، قابل جست‌وجو و بدون برخورد.
  • کد قدیمی، اسکریپت و قالب: یک بار Globals::register() را صدا بزنید و سبک کوتاه قبلی را نگه دارید.
  • لاراول: هر دو ممکن است؛ پرووایدر تابع سراسری اضافه نمی‌کند، پس اگر خواستید Globals::register() را در AppServiceProvider::register() صدا بزنید یا در Blade و کلاس‌ها توابع فضای‌نامی را import کنید.
