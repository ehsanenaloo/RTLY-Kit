نصب و کشف خودکار

جز Composer به هیچ چیز دیگری نیاز نیست. بسته سرویس‌پرووایدر و نام مستعار فاساد را در composer.json زیر extra.laravel اعلام کرده است؛ پس کشف خودکار بسته‌های لاراول در composer install یا composer update بعدی آن‌ها را ثبت می‌کند.

composer require enaxon/rtly-kit

یکپارچگی لاراول از اجزای illuminate/support، illuminate/translation، illuminate/validation و illuminate/database استفاده می‌کند که هر برنامهٔ لاراول از قبل دارد. مجموعهٔ آزمون روی این اجزا با نسخهٔ ۱۱ و ۱۲ اجرا می‌شود (قید توسعه ^11.0||^12.0)؛ خود کتابخانه فقط PHP 8.2 می‌خواهد و بدون لاراول هم کار می‌کند.

نکته. آزمون‌های یکپارچگی کلاس‌های واقعی container، translator، validation factory و مدل Eloquent را اجرا می‌کنند، نه یک اسکلت کامل برنامهٔ لاراول. نمونه‌کدهای این صفحه‌ها هم به همین شیوه اجرا شده‌اند.

اگر برنامهٔ شما کشف خودکار این بسته را خاموش کرده است ("dont-discover": ["enaxon/rtly-kit"])، پرووایدر را خودتان ثبت کنید. در لاراول ۱۱ و بالاتر آن را به bootstrap/providers.php اضافه کنید:

return [
    App\Providers\AppServiceProvider::class,
    RtlyKit\Laravel\RtlyKitServiceProvider::class,
];

در ساختار قدیمی همین کلاس را به آرایهٔ providers در config/app.php اضافه کنید. فایل پیکربندی برای انتشار و مایگریشن وجود ندارد.

سرویس‌پرووایدر چه می‌کند

کلاس RtlyKit\Laravel\RtlyKitServiceProvider در هر مرحله یک کار مشخص دارد:

  • register() یک singleton با کلید rtly-kit.jalali می‌بندد، از نوع RtlyKit\Laravel\JalaliFactory. این همان شیء پشت فاساد است.
  • boot() سه کار می‌کند: ماکروهای Carbon را نصب می‌کند (ماکروهای Carbon)، ترجمه‌های بسته را با فضای نام rtly-kit بارگیری می‌کند و اگر container یک validation factory داشته باشد، قواعد اعتبارسنجی را ثبت می‌کند (اعتبارسنجی و کست).
نکته. پرووایدر هیچ تابع سراسری ثبت نمی‌کند. یک آزمون پرووایدر را بوت می‌کند و تأیید می‌کند که پس از آن هیچ‌کدام از ۲۷ نام کوتاه وجود ندارد. اگر نام‌های کوتاه سراسری می‌خواهید، خودتان \RtlyKit\Globals::register() را صدا بزنید؛ توابع کمکی و سراسری را ببینید.

اگر validator در container از نوع Illuminate\Validation\Factory نباشد (جایگزین سفارشی)، پرووایدر آن را دست‌نخورده می‌گذارد و به‌جای شکست، ثبت قواعد را رد می‌کند.

فاساد Jalali

نام مستعار Jalali (کلاس RtlyKit\Laravel\Facades\Jalali) به factory می‌رسد. چهار متد دارد که سازنده‌های ایستای RtlyKit\Calendar\Jalali را بازتاب می‌دهند:

use RtlyKit\Laravel\Facades\Jalali;

echo Jalali::create(1404, 1, 1)->format('Y/m/d l');   // 1404/01/01 جمعه
echo Jalali::make('2025-03-21')->toDateString();       // 1404/01/01
echo get_class(Jalali::now());                         // RtlyKit\Calendar\Jalali
// Jalali::today() هم موجود است

هر فراخوانی یک شیء معمولی و تغییرناپذیر Jalali برمی‌گرداند، پس هرچه در صفحهٔ تقویم جلالی آمده اینجا هم صادق است. factory یک singleton است و app('rtly-kit.jalali') همیشه همان نمونه را می‌دهد.

فاساد اختیاری است. در کلاس‌ها می‌توانید کلاس را مستقیم import کنید یا از تابع فضای‌نامی \RtlyKit\jdate() استفاده کنید؛ در آزمون‌ها چیزی برای fake کردن نیست، چون factory حالت ندارد.

ترجمه‌ها: فارسی، انگلیسی، عربی

پرووایدر loadTranslationsFrom() را با فضای نام rtly-kit صدا می‌زند؛ پس پیام‌ها زیر rtly-kit::validation.* هستند و از زبان برنامه پیروی می‌کنند. سه مجموعهٔ کامل هست و هر قاعده یک خط دارد:

کلیدfaen
national_code:attribute کد ملی معتبر نیست.The :attribute is not a valid Iranian national code.
sheba:attribute شماره شبا معتبر نیست.The :attribute is not a valid Iranian Sheba (IBAN).
bank_card:attribute شماره کارت بانکی معتبر نیست.The :attribute is not a valid Iranian bank card.
iran_mobile، mobile:attribute شماره موبایل معتبر نیست.The :attribute is not a valid Iranian mobile number.
postal_code:attribute کد پستی معتبر نیست.The :attribute is not a valid Iranian postal code.
vehicle_plate:attribute پلاک خودرو معتبر نیست.The :attribute is not a valid Iranian vehicle plate.

فایل عربی در بسته resources/lang/ar/validation.php است و کلیدهای یکسان دارد. همین قاعده در سه زبان:

// فیلدی به نام national_code، مقدار '1234567890'، قاعدهٔ national_code
// locale fa: national code کد ملی معتبر نیست.
// locale en: The national code is not a valid Iranian national code.
// locale ar: national code ليس رقماً وطنياً إيرانياً صالحاً.

(لاراول نام فیلد national_code را به برچسب «national code» تبدیل می‌کند؛ برای جملهٔ طبیعی، برچسب مناسب را در ترجمه‌های attributes بدهید.)

اگر زبان فعال خطی نداشته باشد، زبان جایگزین معمول لاراول (app.fallback_locale) به کار می‌رود. اگر اصلاً ترجمه‌ای پیدا نشود، متن انگلیسی داخلی آخرین راه است.

بازنویسی پیام

چیزی را منتشر (publish) نمی‌کنید. از باریک‌ترین تا گسترده‌ترین، هرکدام را که مناسب است انتخاب کنید:

  1. برای یک فراخوانی: پیام سفارشی را به‌روش معمول به validator یا $request->validate() بدهید، مثلاً با کلید postal_code یا zip.postal_code. پیام سفارشی همیشه برنده است.
  2. در کل برنامه: خط قاعده را به lang/fa/validation.php خودتان اضافه کنید (کلید همان نام قاعده است، مثلاً 'sheba' => 'شبای :attribute اشتباه است.'). خط validation.<rule> برنامه بر خط بسته ترجیح داده می‌شود.
  3. جایگزینی متن‌های بسته: فایل lang/vendor/rtly-kit/fa/validation.php (یا en، ar) را بسازید. سازوکار استاندارد vendor-override لاراول آن را روی فایل بسته بارگیری می‌کند؛ فقط کلیدهای تغییرکرده را بنویسید.

خروجی راستی‌آزمایی‌شدهٔ گزینه‌های ۲ و ۳ با زبان fa:

// lang/vendor/rtly-kit/fa/validation.php  ->  ['national_code' => 'کد ملی :attribute درست نیست.']
// lang/fa/validation.php                  ->  ['sheba' => 'شبای :attribute اشتباه است.']
// پیام سفارشی روی فراخوانی               ->  ['postal_code' => 'کد پستی :attribute نادرست']
//
// national_code: کد ملی x درست نیست.
// sheba:         شبای x اشتباه است.
// postal_code:   کد پستی x نادرست

نام فیلد در این مثال‌ها x است و برای همین x در جمله‌ها می‌آید. در فرم واقعی، برچسب خوانا را در آرایهٔ attributes فایل validation.php بدهید.

پیکربندی

فایل پیکربندی وجود ندارد. رفتار با طراحی و زبان برنامه تعیین می‌شود. کتابخانه منطقهٔ زمانی پیش‌فرض را از PHP (date_default_timezone_get()) می‌خواند و لاراول آن را از config('app.timezone') تنظیم می‌کند؛ پس Jalali::now() از منطقهٔ زمانی برنامهٔ شما پیروی می‌کند.

محدودیت شناخته‌شده. اگر هنگام بوت پرووایدر validation factory در container بسته نشده باشد، قواعد ثبت نمی‌شوند و بعداً هم تنبل‌وار ثبت نخواهند شد. این فقط در بوت‌استرپ‌های غیرمعمول پیش می‌آید (مثلاً container فقط‌کنسول بدون سرویس اعتبارسنجی).

بعدی: قواعد اعتبارسنجی و کست Eloquent.
