شروع سریع

<?php
require 'vendor/autoload.php';

use RtlyKit\Validation\Mobile;
use RtlyKit\Validation\PostalCode;
use RtlyKit\Validation\VehiclePlate;
use function RtlyKit\is_mobile;
use function RtlyKit\is_postal_code;
use function RtlyKit\is_vehicle_plate;

var_dump(is_mobile('+98 912 123 4567'));          // bool(true)
var_dump(is_postal_code('۱۲۳۴۵-۶۷۸۹۰'));          // bool(true)
var_dump(is_vehicle_plate('12ب345 ایران 67'));    // bool(true)

echo Mobile::getOperator('09121234567'), "\n";    // همراه اول

هر سه قرارداد Validator را پیاده می‌کنند. توابع کمکی‌شان validate_mobile()، validate_postal_code() و validate_vehicle_plate() است.

شمارهٔ موبایل

شکل‌های پذیرفته‌شده

Mobile همه‌چیز را به شکل ملی 09xxxxxxxxx (۱۱ رقم) نرمال می‌کند. این پنج املا را می‌پذیرد، با ارقام فارسی یا عربی و با فاصله، خط تیره یا پرانتز در میانه:

ورودیnormalized
0912123456709121234567
912123456709121234567
98912123456709121234567
+98912123456709121234567
0098912123456709121234567
۰۹۱۲ ۱۲۳ ۴۵۶۷09121234567
(0912) 123-456709121234567

چون Mobile فقط رقم‌ها را نگه می‌دارد، هر جداکنندهٔ غیررقمی کنار گذاشته می‌شود. عدد صحیح مثل 9121234567 هم پذیرفته می‌شود (صفر ابتدایی ندارد که از دست برود، پس به شکل ۱۰ رقمی خوانده می‌شود).

قاعده

اعتبار یک بررسی قالب است: پس از نرمال‌سازی شماره باید با 09 شروع شود، سپس رقمی از ۰ تا ۴ یا ۹ بیاید و هشت رقم دیگر. این‌ها بلوک‌های 090x تا 094x و 099x هستند که به شبکه‌های تلفن همراه اختصاص یافته‌اند. هر چیز دیگر، مثل 0950... یا شمارهٔ ۱۰ رقمی، invalid_format می‌دهد.

$r = Mobile::validate('09121234567');
echo json_encode($r->details(), JSON_UNESCAPED_UNICODE);
// {"normalized":"09121234567","operator":"همراه اول"}

print_r(Mobile::validate('09501234567')->errors());   // [invalid_format]
print_r(Mobile::validate('0912123456')->errors());    // [invalid_format]
echo Mobile::normalize('+98 912 123 4567');           // 09121234567

اشارهٔ اپراتور

details()['operator'] و Mobile::getOperator() شماره را در جدول کوچکی از پیش‌شماره‌های جاافتاده جست‌وجو می‌کنند: همراه اول (0910 تا 0919 و 0990 تا 0994)، ایرانسل (0900 تا 0905، 0930، 0933، 0935 تا 0939)، رایتل (0920 تا 0922)، شاتل موبایل (0998) و آپتل (09991). طولانی‌ترین پیش‌شمارهٔ منطبق برنده است. برای شمارهٔ معتبری که پیش‌شمارهٔ آن در جدول نیست اپراتور null است:

echo Mobile::getOperator('09351234567'), "\n";           // ایرانسل
echo Mobile::getOperator('09981234567'), "\n";           // شاتل موبایل
echo Mobile::getOperator('09991012345'), "\n";           // آپتل
var_dump(Mobile::validate('09951234567')->isValid());   // bool(true)
var_dump(Mobile::getOperator('09951234567'));            // NULL، معتبر اما در جدول نیست
var_dump(Mobile::getOperator('09501234567'));            // NULL، شمارهٔ نامعتبر
محدودیت شناخته‌شده. اپراتور فقط اشاره‌ای بر پایهٔ پیش‌شماره است. قابلیت حفظ شماره (MNP) اجازه می‌دهد با تغییر اپراتور شماره حفظ شود؛ پس پیش‌شماره هرگز اپراتور فعلی را تضمین نمی‌کند. جدول عمداً محافظه‌کار است: بلوک‌هایی که تخصیصشان در منابع مختلف فرق دارد (مثلاً 0931، 0932، 0934، 0940 تا 0949 و بیشتر 0995 تا 0999) حذف شده‌اند و null برمی‌گردانند، هرچند شماره همچنان معتبر است. این جدول منبع مشخصی ندارد که جداگانه ذکر شده باشد؛ دقت و داده‌ها را ببینید. مسیریابی پیامک یا صورتحساب را بر آن بنا نکنید.

جزئیات: normalized و operator. تنها کلیدهای خطا invalid_format، invalid_type و input_too_long هستند. تلفن ثابت و شمارهٔ بین‌المللی پذیرفته نمی‌شود.

کدپستی

کدپستی ایران ۱۰ رقم دارد و هرگز با 0 شروع نمی‌شود. PostalCode فقط رقم‌ها را نگه می‌دارد (ابتدا ارقام فارسی و عربی تبدیل می‌شود، سپس جداکننده‌هایی مثل فاصله و خط تیره حذف می‌شود) و طول و رقم اول را بررسی می‌کند:

$r = PostalCode::validate('۱۲۳۴۵-۶۷۸۹۰');
echo json_encode($r->details());   // {"normalized":"1234567890"}

print_r(PostalCode::validate('12345')->errors());          // [invalid_length]
print_r(PostalCode::validate('123456789012')->errors());   // [invalid_length]
print_r(PostalCode::validate('0123456789')->errors());     // [invalid_format]
خطامعنا
invalid_lengthتعداد ارقام ۱۰ نیست
invalid_formatکد با 0 شروع می‌شود
invalid_type، input_too_longپردازش ورودی را ببینید
فقط قالب. کدپستی رقم کنترل ندارد و بازهٔ منطقه‌ای هم بررسی نمی‌شود: کد ۱۰ رقمی که با 0 شروع نشود معتبر است، حتی اگر پست آن را تخصیص نداده باشد. عدد صحیحی مثل 1234567890 پذیرفته می‌شود چون کد معتبر هرگز با صفر شروع نمی‌شود، اما نگه‌داری کدپستی به صورت رشته همچنان عادت امن‌تری است.

پلاک خودرو

قالب

VehiclePlate پلاک رایج سواری را می‌شناسد: دو رقم، یک حرف، سه رقم و کد دورقمی ایران، به شکل 12ب345 ایران 67. واژهٔ «ایران»، فاصله، خط تیره، زیرخط و نیم‌فاصله نادیده گرفته می‌شود؛ پس همهٔ این شکل‌ها یک پلاک‌اند:

echo VehiclePlate::normalize('۱۲ ب ۳۴۵ ایران ۶۷');   // 12ب34567

$r = VehiclePlate::validate('12ب345 ایران 67');
echo json_encode($r->details(), JSON_UNESCAPED_UNICODE);
// {"normalized":"12ب34567","two_digit":"12","letter":"ب","three_digit":"345","region":"67"}

print_r(VehiclePlate::parse('12ب345 ایران 67'));
// Array ( [two_digit] => 12 [letter] => ب [three_digit] => 345 [region] => 67 )
var_dump(VehiclePlate::parse('xx'));   // NULL

حرف‌ها

حرف باید یکی از این‌ها باشد: الف ب پ ت ث ج د ز س ش ص ط ع ف ق ک گ ل م ن و ه ی ژ. شکل بلند الف یک حرف شمرده می‌شود. D و S لاتین برای پلاک‌های دیپلمات و ویژه پذیرفته می‌شود. صورت‌های عربی حروف ابتدا نرمال می‌شوند؛ پس ك و ي به‌صورت ک و ی خوانده می‌شوند:

echo json_encode(VehiclePlate::validate('12ي34567')->details(), JSON_UNESCAPED_UNICODE);
// {"normalized":"12ی34567","two_digit":"12","letter":"ی","three_digit":"345","region":"67"}

var_dump(VehiclePlate::isValid('12D34567'));       // bool(true)
var_dump(VehiclePlate::isValid('12الف34567'));     // bool(true)

خطاها

  • invalid_format: قالب نمی‌خواند (تعداد ارقام نادرست، حرف غیرمجاز یا بخشی که جا افتاده).
  • invalid_region: قالب می‌خواند اما کد ایران 00، بخش دورقمی 00 یا بخش سه‌رقمی 000 است. بخش‌های تجزیه‌شده همچنان در details() هست.
print_r(VehiclePlate::validate('12ب345')->errors());       // [invalid_format]
print_r(VehiclePlate::validate('12ب34500')->errors());     // [invalid_region]
print_r(VehiclePlate::validate('00ب34567')->errors());     // [invalid_region]
محدودیت شناخته‌شده. این اعتبارسنج قالب و غیرصفر بودن عددها را بررسی می‌کند. نمی‌داند کدام کد ایران وجود دارد، کدام حرف برای کدام نوع خودرو است، و خانواده‌های دیگر پلاک (موتورسیکلت، قالب‌های قدیمی، پلاک مناطق آزاد و دولتی) مدل نشده‌اند. نتیجهٔ معتبر یعنی پلاک خوش‌قالب است، نه اینکه صادر شده باشد.

VehiclePlate::parse() چهار بخش را به صورت آرایه برمی‌گرداند، یا null وقتی پلاک با همان قاعده‌های validate() معتبر نباشد.
