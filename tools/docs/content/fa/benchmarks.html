ابتدا این را بخوانید. این‌ها ریزبنچمارک سه سناریوی کوچک‌اند که یک بار روی یک ماشین اجرا شده‌اند. هزینهٔ نسبی را برای همین بار کاری نشان می‌دهند، نه حکم کلی. پیش از نقل هر عددی، خودتان با دستور زیر دوباره اجرا کنید.

چه چیزی مقایسه شده

پکیج morilog/jalali نسخهٔ 3.5.0 (پرکاربردترین پکیج جلالی) در برابر RTLY-Kit روی سه عملیات:

<?php
require __DIR__.'/vendor/autoload.php';

echo Jalali::make('2025-03-21')->format('Y/m/d'), "\n";                       // 1404/01/01

echo Jalali::create(1404, 1, 1)->addDays(100)->format('Y/m/d'), "\n";        // 1404/04/08

نتیجه‌ها

یک اجرا، میانهٔ ۵ تکرار از ۲۰٬۰۰۰ تکرارِ حلقه. محیط: PHP 8.2.30 در حالت CLI داخل Docker روی ویندوز ۱۱، با opcache.enable_cli=1.

اوج حافظهٔ کل فرایند، با بارگذاری هر دو کتابخانه، ۴ مگابایت (MiB) بود.

یک اجرای قبلیِ موردی، بدون opcache و با ترکیب دیگری از سناریوها، فاصلهٔ بیشتری نشان داد (حدود ۲۵ برابر). همین پراکندگی خودش درس است: نسبت به سناریو و پیکربندی PHP بستگی دارد.

راستی‌آزمایی درستی

برای تک‌تکِ روزها از 1900-01-01 تا 2099-12-27 (۷۳٬۰۰۰ روز پیاپی) تاریخ جلالیِ RTLY-Kit با نتیجهٔ CalendarUtils::toJalali در morilog یکسان است: ۰ اختلاف. هر دو قاعدهٔ حسابی کبیسهٔ ۳۳ساله را پیاده می‌کنند؛ پس توافق یعنی این دو با هم سازگارند. این به معنای انطباق هیچ‌کدام با تقویم نجومی رسمی ایران در دوردست از زمان حاضر نیست (به دقت و داده‌ها نگاه کنید).

چرا تفاوت دارند؟

این را پروفایل نکرده‌ایم؛ پس موارد زیر محتمل‌اند، نه اثبات‌شده. RTLY-Kit یک DateTimeImmutable ساده را می‌پوشاند و با حساب اعداد صحیح تبدیل می‌کند. morilog شیءهای Carbon می‌سازد و دستکاری می‌کند که بسیار بزرگ‌ترند (پارس و ماشین‌آلات زبان‌محلی)؛ پس بخشی از فاصله انتخابِ معماری است، نه فقط الگوریتم تبدیل. اگر همه‌جا از Carbon استفاده می‌کنید، فاصلهٔ مربوط به شما شاید کمتر باشد.

تکرار آزمایش

بنچمارک در مخزن، در پوشهٔ tools/benchmark است. composer.json آن، RTLY-Kit را از درخت کاری و morilog/jalali را در پوشهٔ vendor/ خودش نصب می‌کند (که جزو بسته نیست). اسکریپت نسخهٔ PHP، تنظیمات opcache و JIT و میانهٔ تکرارها را چاپ می‌کند.

docker compose -f tools/docker-compose.yml run --rm php sh -c 'cd tools/benchmark && composer install -n && php -d opcache.enable_cli=1 run.php 20000 5'

عددهای ماشین‌های مختلف با هم قابل مقایسه نیستند.
