این کلاس چه می‌کند

کلاس RtlyKit\Holiday\IranHolidays چهار پرسش دربارهٔ یک تاریخ جلالی را پاسخ می‌دهد: آیا تعطیل رسمی است، عنوان تعطیلی چیست، آیا آخر هفته است و روز کاری بعدی کدام است. همهٔ متدها static هستند و کلاس final است. عنوان‌ها همان‌طور که در تقویم رسمی آمده‌اند، فارسی برگردانده می‌شوند.

دو نوع تعطیلی با هم ترکیب شده‌اند:

  • تعطیلات ثابت شمسی هر سال در یک تاریخ جلالی می‌افتند (نوروز، ۲۲ بهمن و مانند آن) و دقیق‌اند.
  • تعطیلات مذهبی (قمری) از تقویم هجری قمری به‌دست می‌آیند و هر سال حدود ۱۱ روز در سال شمسی جابه‌جا می‌شوند. این‌ها تخمینی‌اند؛ بخش دقت و محدودیت‌ها را ببینید.

بررسی یک روز

هر جست‌وجو یا یک شیء Jalali می‌پذیرد یا سه عدد صحیح (سال، ماه، روز).

use RtlyKit\Calendar\Jalali;
use RtlyKit\Holiday\IranHolidays;
use function RtlyKit\is_iran_holiday;

var_dump(IranHolidays::isHoliday(1404, 11, 22));              // bool(true)
var_dump(IranHolidays::getTitle(1404, 11, 22));               // string(38) "پیروزی انقلاب اسلامی"
var_dump(IranHolidays::isHoliday(Jalali::create(1404, 1, 5))); // bool(false)
var_dump(is_iran_holiday(1404, 1, 1));                        // bool(true)  (تابع کمکی در فضای نام)

متد getTitle() نخستین عنوان یا null را برمی‌گرداند. اگر دو مناسبت در یک روز بیفتند، از getTitles() استفاده کنید؛ فهرستی است که تعطیلی ثابت در آغاز و تعطیلی مذهبی پس از آن می‌آید:

print_r(IranHolidays::getTitles(Jalali::create(1404, 1, 1)));
// Array ( [0] => جشن نوروز [1] => شهادت امام علی )

مورد دوم از آن‌رو آمده که تقویم ام‌القری ۲۱ رمضان ۱۴۴۶ را روی ۱ فروردین ۱۴۰۴ قرار می‌دهد. این تاریخ محاسبه‌شده است نه اعلام‌شده، و دقیقاً به همین دلیل تعطیلات مذهبی تخمینی‌اند. محدودیت را در ادامه ببینید.

فهرست کل سال

سه متد یک سال کامل را برمی‌گردانند؛ کلیدها رشتهٔ Y/m/d و به ترتیب صعودی‌اند:

  • allFixed(int $year) فقط تعطیلات ثابت شمسی را برمی‌گرداند و برای هر تاریخ یک عنوان دارد.
  • all(int $year) تعطیلات ثابت و مذهبی را برمی‌گرداند؛ عنوان‌های یک روز با / به هم وصل می‌شوند.
  • allTitles(int $year) شکل ساخت‌یافته است: هر مقدار یک list<string> است.
foreach (IranHolidays::allFixed(1404) as $date => $title) {
    echo $date, '  ', $title, "\n";
}
// 1404/01/01  جشن نوروز
// 1404/01/02  عید نوروز
// 1404/01/03  عید نوروز
// 1404/01/04  عید نوروز
// 1404/01/12  روز جمهوری اسلامی
// 1404/01/13  روز طبیعت
// 1404/03/14  رحلت امام خمینی
// 1404/03/15  قیام ۱۵ خرداد
// 1404/11/22  پیروزی انقلاب اسلامی
// 1404/12/29  ملی شدن صنعت نفت

echo count(IranHolidays::all(1404));    // 27 (تعطیلات ثابت و مذهبی، یک ورودی برای هر روز)

بخش مذهبی ۱۴۰۴ برای نمونه شامل 1404/01/10 عید فطر، 1404/01/11 تعطیل عید فطر، 1404/03/16 عید قربان، 1404/03/24 عید غدیر خم، 1404/04/13 تاسوعای حسینی و 1404/04/14 عاشورای حسینی است. توجه کنید که عید فطر روی 1404/12/29 هم می‌افتد، چون سال قمری کوتاه‌تر از سال شمسی است و یک مناسبت می‌تواند دو بار در یک سال شمسی رخ دهد؛ all() در آن روز ملی شدن صنعت نفت / عید فطر را می‌دهد.

آخر هفته و روز کاری

سه متد کمکی یک شیء Jalali می‌گیرند:

  • isWeekend($date) فقط در جمعه برابر true است.
  • isBusinessDay($date) وقتی true است که روز نه آخر هفته باشد و نه تعطیل رسمی.
  • nextBusinessDay($date) نخستین روز کاری پس از تاریخ داده‌شده را برمی‌گرداند (خود آن روز حساب نمی‌شود).
foreach ([Jalali::create(1404, 11, 20), Jalali::create(1404, 11, 21), Jalali::create(1404, 11, 22)] as $d) {
    echo $d->toDateString(),
        ' weekend=', var_export(IranHolidays::isWeekend($d), true),
        ' business=', var_export(IranHolidays::isBusinessDay($d), true),
        ' next=', IranHolidays::nextBusinessDay($d)->toDateString(), "\n";
}
// 1404/11/20 weekend=false business=true next=1404/11/21
// 1404/11/21 weekend=false business=true next=1404/11/23
// 1404/11/22 weekend=false business=false next=1404/11/23
نکته. فقط جمعه آخر هفته حساب می‌شود. پنجشنبه اینجا روز کاری است و نیم‌روز پنجشنبه، تقویم استانی و تعطیلی‌های موردی (مثل آلودگی هوا یا اعلام دولت) در نظر گرفته نمی‌شوند. اگر سازمان شما پنجشنبه‌ها تعطیل است، پس از isBusinessDay() خودتان آن را فیلتر کنید.

ورودی نامعتبر

ورودی نادرست یک زیرکلاس RtlyKitException پرتاب می‌کند و هرگز خطای خام PHP نمی‌دهد. مدیریت خطا را ببینید.

IranHolidays::isHoliday(1404, 13, 1);  // InvalidDateException: Invalid Jalali date: 1404/13/1
IranHolidays::isHoliday(1404);         // InvalidDateException: Month and day are required when the year is given as int.
IranHolidays::all(99999);              // InvalidDateException (سال خارج از بازهٔ ‎-620..9377)

دقت و محدودیت‌ها

محدودیت شناخته‌شده. تعطیلات ثابت شمسی دقیق‌اند. تعطیلات مذهبی از تقویم هجری ام‌القری محاسبه می‌شوند، اما ایران تاریخ مناسبت‌های مذهبی را با رؤیت هلال تعیین می‌کند. بنابراین روز اعلام‌شدهٔ رسمی ممکن است ۱ تا ۲ روز با روز محاسبه‌شده فرق داشته باشد. تعطیلات مذهبی را تخمین بدانید و پیش از تکیه بر آن‌ها برای حقوق و دستمزد، مهلت‌ها یا تاریخ‌های حقوقی، با اعلام رسمی تطبیق دهید.
  • بازه. تعطیلات مذهبی فقط درون جدول ام‌القری تعبیه‌شده گزارش می‌شوند (سال‌های هجری ۱۳۰۰ تا ۱۵۰۰، یعنی ۱۸۸۲-۱۱-۱۲ تا ۲۰۷۷-۱۱-۱۶). بیرون از آن، isHoliday()، getTitles()، all() و allTitles() فقط تعطیلات ثابت شمسی را می‌دهند، چون برون‌یابی جدولی برای تعطیلات قابل اعتماد نیست. نمونه: IranHolidays::getTitles(Jalali::create(1500, 1, 1)) فقط ["جشن نوروز"] را برمی‌گرداند.
  • پوشش داده‌نشده. تعطیلی‌های موردی که دولت اعلام می‌کند و مناسبت‌هایی که تعطیل نیستند.
  • منبع داده در صفحهٔ دقت و داده‌ها آمده است.
